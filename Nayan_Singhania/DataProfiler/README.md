# Data Diagnostics & Cleaning Pipeline

This project is a small Data Quality web app for diagnosing and cleaning a messy customer dataset.

The website lets you upload a CSV file, view data quality errors, calculate an overall quality score, run the Python cleaning pipeline, download the cleaned CSV, and upload it again to verify that the score reaches 100%.

## Files

- `messy_customers50.csv` - raw messy customer dataset
- `index.html` - frontend dashboard for upload, diagnostics, cleaning, preview, and download
- `cleaner.py` - Python/pandas cleaning pipeline and local server
- `clean_customers50.csv` - cleaned output dataset generated by the pipeline

## What The App Checks

The dashboard checks common data quality issues such as:

- Missing or invalid names
- Invalid email casing or domains
- Invalid ages
- Invalid or future signup dates
- Bad account balance formats
- Invalid phone number formats
- Inconsistent city/name casing

## Cleaning Rules

The Python pipeline performs transformations such as:

- Trim and title-case names and cities
- Lowercase emails
- Replace invalid/missing email domains with the most frequent valid domain
- Convert invalid age values to `N/A`
- Convert invalid signup dates to `N/A`
- Remove currency symbols from balances and convert negatives to positive values
- Standardize phone numbers, or set invalid/missing phones to `N/A`

## Setup

Make sure Python and pandas are installed.

Install pandas if needed:

```bash
python3 -m pip install pandas
```

## Run The Website

From the project folder, start the local server:

```bash
python3 cleaner.py serve
```

Then open this URL in your browser:

```text
http://localhost:8000
```

Keep the terminal running while using the website. The `Clean Dataset` button sends the uploaded CSV to `cleaner.py`, so the Python server must be active.

## Demo Workflow

1. Start the server with `python3 cleaner.py serve`.
2. Open `http://localhost:8000`.
3. Upload `messy_customers50.csv`.
4. Review the quality score and listed errors.
5. Click `Clean Dataset`.
6. Download the cleaned CSV.
7. Upload the cleaned CSV again to confirm `100%` quality score.

## Command-Line Cleaning

You can also run the cleaning pipeline directly:

```bash
python3 cleaner.py messy_customers50.csv clean_customers50.csv
```

This generates `clean_customers50.csv` without using the website.
